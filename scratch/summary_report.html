ส่วนที่ 1 สรุปเนื้อหาโครงงานเทคโนโลยีสารสนเทศ (บทที่ 1 - 3)

โครงงาน: ระบบแดชบอร์ดประเมินและติดตามความปลอดภัยทางไซเบอร์ มหาวิทยาลัยขอนแก่น (KKU Security Scorecard & Vulnerability Management Dashboard)

บทที่ 1: บทนำ (Introduction)

ความเป็นมาและความสำคัญ: เครือข่าย มข. มีขนาดใหญ่ครอบคลุมกว่า 21 คณะ/หน่วยงาน เผชิญความเสี่ยงทางไซเบอร์สูง เช่น การละเลยการ Patch อุปกรณ์, DNS Spoofing และมัลแวร์ เดิมขาดเครื่องมือศูนย์กลางในการประเมินภาพรวมความปลอดภัย
วัตถุประสงค์: พัฒนาระบบประเมิน Security Scorecard แบบเรียลไทม์, สร้างแผนที่ Interactive Campus Map แสดงเกรดความปลอดภัย (A-F) รายคณะ, รองรับการนำเข้าข้อมูลทั้ง API และ CSV Manual Import พร้อมเข้ารหัสลับ API Key ด้วย AES-256-GCM

บทที่ 2: ทฤษฎีและเทคโนโลยีที่เกี่ยวข้อง

  • Security Rating (4 เสาหลัก): ประเมินจาก WiFi/Network, Patch & EDR (CVE), Portal/App, และ DNS/Anti-Spoofing
  • Frontend: Next.js, Leaflet.js (Interactive Map), Tailwind CSS
  • Backend & DB: Node.js (Express Framework), PostgreSQL, Prisma ORM, เข้ารหัสด้วย AES-256-GCM

บทที่ 3: การออกแบบและสถาปัตยกรรมระบบ

  • Architecture: Full-stack Monorepo บน Docker-compose (Nginx Proxy 4333, Next.js 3000, Express 5000, PostgreSQL 5432)
  • Domain Mapping: อัลกอริทึม Token-based matching จำแนกโดเมนย่อยเข้าสู่คณะที่รับผิดชอบโดยอัตโนมัติ
  • Database Models: User, Organization, Domain, Issue, Import, FacultyDailyStat

สรุปสาระสำคัญและกิจกรรมที่เข้าร่วม (Key Highlights & Experience)

  • ความเป็นที่ 1 ของ Fortinet (Market Leadership): การนำเสนอภาพรวมความเป็นผู้นำอันดับ 1 ด้านโซลูชันความปลอดภัยระดับโลก ด้วยวิสัยทัศน์ Security Fabric ที่เชื่อมโยงอุปกรณ์และระบบความปลอดภัยไซเบอร์ทั้งหมดเข้าไว้ด้วยกันอย่างเป็นเอกภาพ
  • แนวทางในยุค AI และภัยคุกคามอนาคต (AI & Machine-Speed Cyber Defense): การขับเคลื่อนระบบป้องกันภัยไซเบอร์สำหรับองค์กรในอนาคตด้วย AI และ Automation เพื่อรับมือกับภัยคุกคามยุคใหม่ที่เกิดขึ้นอย่างรวดเร็วระดับ Machine-Speed ช่วยตรวจจับ คัดกรอง และสกัดกั้นภัยคุกคามได้แบบอัตโนมัติทันที
  • บรรยากาศและสวัสดิการในงาน: ผู้เข้าร่วมสัมมนาได้รับความรู้เต็มอิ่ม พร้อมสวัสดิการอาหารกลางวัน (รับประทานข้าวเที่ยงฟรี) และโอกาสแลกเปลี่ยนประสบการณ์กับผู้เชี่ยวชาญด้าน Cybersecurity ระดับประเทศ
